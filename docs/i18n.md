# i18n — convention du site

Deux langues : `fr` (défaut) et `en`. La langue vient du cookie `tdl-lang`, posé par le
sélecteur de la barre de navigation et lu par `src/middleware.ts` → `Astro.locals.lang`.
Aucune URL ne change : la page est rendue côté serveur dans la bonne langue.

## Règles

1. **Ne pas traduire les données du jeu** : noms d'objets, noms de comtés, pseudos,
   noms de personnages, contenu saisi par les joueurs. On traduit l'interface.
2. **Anglais britannique**, ton du site : sobre, direct, pas de marketing.
3. **Aucune classe, aucun markup, aucune logique ne change** : seuls les textes.
4. Les montants/dates passent par `locale(lang)` ou `nf(lang)` de `src/i18n`.
5. Une page ne doit plus être prérendue (`export const prerender = false`) : la langue
   dépend de la requête.

## Page Astro

```astro
---
import Layout from '../layouts/Layout.astro';

const { lang = 'fr' } = Astro.locals;
const copy = {
  fr: { title: 'Titre — Le Trône des Lames', heading: 'Titre' },
  en: { title: 'Title — The Throne of Blades', heading: 'Title' },
}[lang];
---

<Layout title={copy.title}>
  <h1>{copy.heading}</h1>
</Layout>
```

## Îlot React

Le composant racine reçoit `lang` et le passe à ses enfants qui affichent du texte.

```tsx
import type { Lang } from '../../i18n';

const STR = {
  fr: { close: 'Fermer', count: (n: number) => `${n} objet${n > 1 ? 's' : ''}` },
  en: { close: 'Close', count: (n: number) => `${n} item${n > 1 ? 's' : ''}` },
};

export default function Panel({ lang = 'fr' }: { lang?: Lang }) {
  const s = STR[lang];
  return <button>{s.close}</button>;
}
```

Dans la page : `<Panel client:load lang={lang} />`.

## Exemples complets

- `src/pages/index.astro` et `src/pages/submit.astro` : pages avec `copy`.
- `src/i18n/index.ts` : `Lang`, `locale`, `nf`, textes de la coque (nav, pied de page).
- `src/components/LanguageToggle.astro` : le sélecteur.
